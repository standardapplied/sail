- **A project, workspace or file a person clicks stays chosen when an answer lands while the mouse button is down.** The Mac app now takes a click's choice as the button goes down, not only when it comes up, so a listing or a redraw that arrives mid-click no longer puts the previous project, workspace row or file back. A press dragged across projects chooses each in turn, as the arrow keys do, and the one under the pointer when the button comes up is the one chosen.
