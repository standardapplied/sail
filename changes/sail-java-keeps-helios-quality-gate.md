- **`mvn verify` keeps the quality gate Helios keeps.** The enforcer requires Java 25, Maven 3.9.14 and a version on every plugin. PMD fails a build on a wildcard import, a dense `switch`, a nested `if` three deep in a test, or a class with too many fields, methods or collaborators or of God-class shape, and prints the class, line, rule and limit. The classes, main and test, that broke the class-level rules when the gate went on are listed once in `config/quality/pmd-exclusions.properties`, which only shrinks: `ci/exclusions` fails a change that adds a class or a rule to it against its merge base, names a class twice, or holds a line other than a comment, a blank or one `Class=Rule[,Rule]` entry, and fails any Java line that could silence PMD (`NOPMD`, or a `@SuppressWarnings` other than one line of javac's warnings), and `ExclusionsShrinkTest` fails on an entry its class no longer bears out. CPD reports repeated blocks of 100 tokens across the reactor. A build-only `architecture` module holds ArchUnit rules for what Sail already keeps: the module directions, picocli and SnakeYAML Engine as the only runtime libraries, picocli in `sail-infra` alone, `Clock.system*` only as a field's initial value, a UUID minted only by `Ids`, nothing `@Deprecated`. The families still to burn down wait in `pmd-main-pending.xml` and `pmd-test-pending.xml`, listed with their counts in AGENTS.md "Quality gate"; `RuleSetsTest` holds gated and pending together to verbatim copies of Helios's two rule files (`config/quality/helios-pmd-*.xml`), rule for rule, every property and XPath. A `mutation` profile runs PIT by hand. CI runs the gate in the Linux unit jobs, with `ci/exclusions`, `architecture` and CPD in `sail-infra`'s; the macOS unit jobs run the tests alone (`ci/check unit <module> --tests-only`, which replaces `--no-coverage`), and a job's install of its upstream modules skips PMD but for `sail-infra`'s Linux job, which writes their reports without judging them. `ci/check`'s wildcard-import grep is gone, and the native builds build `-pl sail-infra -am`, so the release never builds `architecture`. Nothing a box runs changes.
