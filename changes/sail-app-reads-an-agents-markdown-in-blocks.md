- **The app reads an agent's Markdown in blocks.** SailKit's new `SailChat` module splits a chat message into its blocks with no new dependency: paragraphs, ATX headings, fenced code with its language word and its lines as written (what Copy gives), bullet and ordered lists (an ordered list keeps its first number) nested by indent, block quotes, rules and GFM pipe tables with their column alignments and ragged rows padded. Inline Markdown is left whole in each block for the Mac to style. The text is the agent's and treated as untrusted: HTML and images stay text, nothing is fetched, lists and quotes nest at most 8 deep (deeper markers are text), a table has at most 32 columns, and a message of 65,536 code points splits in linear time. As a message streams in, an unclosed fence is already code, and a block settles once a finished line after it starts another, so the view lays out each settled block once. Indented code, setext headings and lazy continuation lines read as paragraph text in this first build.
