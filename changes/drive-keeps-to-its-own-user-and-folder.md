- **The app's drive keeps to its own account and its own folder.** `ci/drive` ended every process on the Mac whose command line held `_pty-host --local`, so on a Mac shared with a person it reached for their terminal host. It now looks only at this account's processes (`pgrep -U`), ends only the hosts Sail apps start from Application Support, by their pids, and does not run at all while this account already has one, since that host's terminals would end with it; the drives it ends are matched on this run's own output folder, and `ci/test-suites` and the drive's `kill` step look only at this account's processes too. The drive's flood files, colour asker and flood pacer, made at fixed paths in `/tmp`, are made in the run's private folder, which `ci/drive` hands over as `SAIL_DRIVE_PRIVATE` (the drive refuses to start without it, and scripts name it as `{private}`) and removes when it ends, so two runs on one Mac never share a file. `ci/drive-check`, run by `ci/test-suites`, proves on stand-ins that another account's host lets the drive go on and this account's own stops it before anything starts.
