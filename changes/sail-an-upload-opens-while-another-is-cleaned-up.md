- **An upload opens while another's leftovers are cleaned up.** A file pasted into a terminal right after another upload in the same session was refused or cancelled could itself be refused as `failed`: the workspace counts the bytes the session's folder holds before it takes the file, and when the other upload's temporary was removed during that count, `find` reported the missing file and the open failed (27 times in 9626 runs on Ubuntu 24.04). The count now passes `-ignore_readdir_race`, so a file that goes while the folder is counted counts as not there, and the upload opens. A folder that really cannot be read is still refused as `failed`. The script runs only inside a Linux workspace; the Mac's own terminal host takes no uploads, so it is unchanged there.
