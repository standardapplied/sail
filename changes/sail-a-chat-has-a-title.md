- **A chat in its workspace's sessions listing has a title.** Each chat row gains `title`: the first line of the person's first message (the first line with words in it, whether that message went to the agent at once or waited for its turn), with every run of spaces, tabs and control characters one space, cut on the last whole word within 80 characters (a single longer word is cut at 80, never inside a character). A chat the person has said nothing in yet has no `title`, so the app says "New chat". A later message never changes it. It is read in the same query that lists the chat, so the listing asks the database nothing more, and it is the person's own words, listed to them alone.
