- **The rules authors keep are checked by a script, in seconds.** `ci/rules` reads the clients' Swift and the modules' Java with one lexer and holds them to the rules a script can decide, each finding naming its file, line, rule and sentence; `ci/rules list` names every rule and whether it is on. On from the start: no "…" in a literal menu item's or button's label, no AppKit list or row outside `SailControls`, and a pull request's one entry. Implemented and tested, and switched on by the pull request that clears each: inline comments, sleeps in Swift tests, design tokens, shared components, and the caps on a function's lines, parameters and nesting and on a file's lines.
- **A pull request adds exactly one entry, `changes/<spec-id>.md`.** `ci/changelog check` refuses a change that adds none, several, or one not named for the spec its branch `agent/<spec-id>` names.
- **Every record a `--json` verb prints is held to its reflection entry by a unit test**, read from the JSON probe and its components' declared types, so a missing entry fails on Linux before the native binary does.
