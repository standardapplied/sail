- **This Mac is a project in Workspaces, listed first, kept on this Mac alone.** The Mac app's projects list has two groups: THIS MAC, holding one project named This Mac with the terminal icon and a Local pill, then the control plane's projects under its host with their count. This Mac's page says which Mac it is and that nothing on it is sent to the control plane, and lists this Mac's terminals, a row each: the tab's title, its folder, Running or Ended, and the shell or how its session ended. Open (Return) shows that terminal in Terminals; End Session (⌘W) ends it as closing it does; New Shell (⌘T) opens a shell in Terminals at once, with no chooser. This Mac cannot be renamed or deleted and has no repositories, agents, size or template; no request names it or this Mac's host. Chosen last, it is where Workspaces opens next time.
- **Untitled shells on this Mac are told apart.** A second untitled shell's tab is "This Mac 2", as a second tab in one workspace is "harbor · dock 2"; a tab the person named or whose program titled it keeps that title.
