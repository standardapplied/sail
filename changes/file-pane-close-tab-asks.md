- **Closing a tab asks about a file's unsaved text however it was last changed.** A redo or undo the text view reports to no delegate was decided only on the next turn, so closing the tab in the same turn could close a file pane over unsaved text without asking; closing a tab now reads the pane's unsaved state through the same door as quitting and closing the file, which decides any such edit first, and nothing outside the pane reads its model's `clean`. A large file loads into the view 16 KiB a turn, half as much as before, so the costliest turn of a 5 MB load stays under one 60 Hz frame.
