- **Create a project from the Mac app.** A control plane with no project now says what a project is and offers Create Project to anyone whose sign-in may both create a project and build its template, and the left panel says "No projects yet." under the control plane's name. Everyone else, who sees only the projects granted to them, is told as before that no project is open to them yet and that an admin adds them, with Check Again. The New project sheet asks for a name, the repositories (each one's folder under `~/workspace/` fills in from its URL until you change it), the agents to install (every harness the control plane knows, all checked; if they cannot be listed, Create waits and Try Again lists them) and a size (Small, Medium, Large or Custom). Create sends the whole project at once; a refusal stands under the field it is about, such as a name already taken or two repositories cloned to one path, with what was typed kept. The new project is chosen in Workspaces at once and its template's build is started. A Create that timed out but reached the control plane is found on the next Create rather than refused as a taken name. With projects listed, Create Project is the + on the control plane's head in the left panel, and a long control plane name gives way to it. The line under an empty Workspaces page that names the control plane now goes onto a second line at a dot, which it drops there, rather than being cut off.
