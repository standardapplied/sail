- **Create a project from the Mac app.** A control plane with no project now says what a project is and offers Create Project to anyone whose sign-in may both create a project and build its template (an admin today; others are told to ask an admin), and the left panel says "No projects yet." under the control plane's name. The New project sheet asks for a name, the repositories (each one's folder under `~/workspace/` fills in from its URL until you change it), the agents to install (every harness the control plane knows, all checked; if they cannot be listed, Create waits and Try Again lists them) and a size (Small, Medium, Large or Custom). Create sends the whole project at once; a refusal stands under the field it is about, such as a name already taken, with what was typed kept. The new project is chosen in Workspaces at once and its template's build is started; if the build could not be asked, Try Again over the project's page asks it again. A Create that timed out but reached the control plane is found on the next Create rather than refused as a taken name. With projects listed, Create Project is the + on the control plane's head in the left panel.
