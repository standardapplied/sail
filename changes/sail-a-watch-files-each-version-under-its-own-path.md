- **A file watch watches every path it is sent.** The files tree's watch stats its set every 250 ms. When a check ran between a newly sent path and that path's version, which can happen on a loaded runner or when the set arrives in pieces, the version was filed under the previous set's last path. That path was then reported changed when it had not changed, and the new path was never watched, so a file or folder the person had open did not refresh. A check now changes nothing about a set being read, and each version is filed under the path it was sent with. The watch protocol is unchanged.
