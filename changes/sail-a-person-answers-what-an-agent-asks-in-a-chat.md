- **A chat's person answers what Claude Code asks.** `POST /v1/sessions/{id}/chat/requests/{request}` takes `{"decision": "allow" | "allow_always" | "deny" | "answer", "message"?, "answers"?}` and answers `200 {"seq"}`, the seq of an `answered` item logged before Claude Code is told: an allow runs the call as it was asked, allow always keeps exactly the rule Claude Code suggested (only when the card offered it), a denial carries the person's words exactly, a question is answered with its own choices or the person's own words, and a plan is approved or sent back. An answer reaches its request once: a second one, one Claude Code no longer waits for (withdrawn, the turn or process ended, a restart, a stop in flight) and one to a request never asked are refused, `409 request_answered`, `409 request_withdrawn` or `404`, and nothing is written; an answer Sail could not log is not sent either, and answering again sends it.
- **Stop and mode in a chat.** `POST /v1/sessions/{id}/chat:interrupt` stops the open turn once and answers `{"stopping"}`; `PUT /v1/sessions/{id}/chat/mode {"mode"}` changes the mode between turns (`409 turn_open` during one), logged as `mode_set` and said back as `mode_changed`, or, with no process, kept for the next one. Never asks is not a chat mode (422).
- **A request waits for its person.** The 5-minute bound that stopped a turn with a request nobody answered is gone: a request now waits as long as it takes, and its process is kept; only a stop Sail asked for and the harness did not take is bounded, and ends the process after five minutes.
