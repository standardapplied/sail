- **New session shows every kind as a choice.** The popover is 388 pt wide and lists each agent the workspace offers, then Shell, as equal rows. Each row has a tile (two letters of the agent's name, or a terminal for Shell), the name, and one line saying how it signs in: the stored default key ("API key “default”"), else its own sign-in ("Your Claude account"), whatever Sign in is set to. Shell's line is "A terminal in dock, no agent". The chosen row has the bar, a check and its tile outlined in ink, and a row under the pointer has its name at full weight. The chosen agent's options stand under its name. Mode is the agent's modes; an agent with one mode shows it off, with the server's note. Sign in says "Already signed in in dock." where the workspace holds the sign-in, the sign-in's own sentence where it does not, and "Or your Claude account, chosen here." where a key is chosen. A mode the server marks `risky` (Bypass permissions, Codex CLI's Full access) has its words in the warning colour after the warning mark. An agent that is not installed is a dimmed row that says "Not installed in harbor"; choosing it shows why in place of its options, and there is no Start. The one primary names the choice ("Start Claude Code", "Start Codex CLI", "Open Shell"), and "Start and Sign In" is gone. Past seven rows, typing narrows them to the names that start with what was typed and chooses the first; ⌫ widens them again.
