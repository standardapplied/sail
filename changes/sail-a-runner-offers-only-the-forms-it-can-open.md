- **A runner offers only the forms it can open.** On a box with no terminal door (no `terminal-listen`) the agents route no longer offers a terminal that is then refused: each offer's `forms` holds only what this box opens now, so Claude Code offers `["chat"]` alone, and a harness left with no form, such as Codex, which has no chat, is not offered at all. Were nothing left to offer, the answer would say why once, as its `refusal`, in the words a terminal is refused with there (`terminal_not_offered`, "This runner offers no terminal over the network; ask an admin."). With a terminal door every offer is as before.
