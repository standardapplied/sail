- **A workspace says what changed since HEAD, and one file's change.** Over a files ticket, `FilesChanges` answers each of the workspace's repositories (the workspace folder and each folder under it that is its own repository) with its branch, the paths that differ from `HEAD` (modified, added, deleted, renamed with its old path, untracked, conflicted) and the paths git ignores as it matched them, an ignored folder one path; each list cut at 5,000, every frame saying how long the answer took. `FilesDiff` answers one file's unified diff. git runs as the workspace's user through one safe invocation that runs none of the repository's code (no fsmonitor, filter, external diff or text conversion, and no transport, so no lazy fetch) and with optional locks off, so an agent's `git` never waits; a repository git refuses is said for it alone, and a file behind a filter (Git LFS and its like) is listed but its diff is not shown; a workspace runs one changes script at a time however many connections ask.
