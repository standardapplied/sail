- **⌘-click a path in a workspace's terminal and the file opens at its line.** Held over `src/App.java:42`, `src/app.ts:12:5`, `src/app.ts(12,5)` or a bare `Package.swift` as compilers and searches print them, ⌘ underlines the path in the text's own ink with the pointing hand; a URL, a time or a version is never one. A ⌘-click looks for it on the workspace (as written when absolute, `~/` the home; otherwise in the folder the terminal last reported, then the workspace's root, then each folder under it) and opens the first found in the tab's file pane at its line, the caret there and a 2 pt accent bar beside it, asking first if the pane holds another file's unsaved text; none found, the terminal's own card says "No file at src/Gone.java in dock." Nothing is typed into the terminal and nothing runs. A ⌘-click on a path goes to the path alone: a program that tracks the mouse still gets every other click.
