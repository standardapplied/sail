- **A workspace's write lock goes with the save that held it past the last connection.** A save answers before it lets go of the workspace's write lock, so a client could close its last connection on the answer while the save still held the lock; the lock was dropped only as the last connection went, and kept for good if a save held it then. The host now also drops it as that save lets go, once no connection to the workspace is left and nothing waits for it.
