- **The darwin sail of each pull request is built on a Blacksmith M4 runner.** Clients' `host` job, which builds the darwin `sail` that SailKit on macOS and SailApp on macOS test against and bundle, runs on `blacksmith-6vcpu-macos-15`: on the trial (sail#542) its native image built in about 70 s instead of 5 to 6.5 minutes, cutting about 5 minutes from every Clients round. Only this lane moved: it holds no secret and never runs in a release (release.yml builds its own darwin binary on GitHub's `macos-15`), while the app lane holds the signing secrets and the other lanes gained too little for their cost or failed on Blacksmith's images (no zfs module, an older Swift, a login shell that resets HOME). Moving it back is the one `runs-on` line of `host` in `clients.yml`.
