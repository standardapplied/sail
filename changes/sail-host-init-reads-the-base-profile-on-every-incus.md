- **`sail host init` run again works on Incus 7.7.** Incus 7.7, which Zabbly's stable repository has served since 27 November 2026, prints `incus profile device list` as a table, not one device name a line. `sail host init` read that list to see whether the base profile `singlr-base` already held its root disk and NIC. On a box initialized before, it saw neither on 7.7, tried to add the root disk again, and stopped at step 6 with `Failed to add root disk to profile: Error: The device already exists`. Adding a ZFS pool to a box with `sudo sail host init --storage zfs …` failed this way. A first `sail host init` on a new box was not affected. Sail now reads the profile from `incus profile show`, which prints the same YAML on every Incus release. The profile keeps its devices, and its root disk stays on its pool. Upgrade Sail and run the command again. A failed run changed nothing on the box: the profile, its pools and the containers on them are as they were.
- **`sail migrate` sees that a 0.58 project's container is stopped whatever language the box speaks.** It looked for the line `Status: STOPPED` in `incus info`, whose label Incus translates (French prints `État : STOPPED`). On such a box it took a stopped container for one whose run had not ended, and would not convert. It now reads the container's state from `incus list --format json`, as every other Sail command does.
