- **A workspace's text file opens beside its terminals and is typed in at once.** ⏎ or a double click on a file in the files panel opens it in the tab's file pane, at the terminals' trailing side behind a divider that drags, its width remembered for that workspace; where the tab cannot give both their least, the pane takes the terminals' place and Show Terminal, or moving the keys, gives it back. Text is decided by content (no NUL and valid UTF-8 in its first 64 KiB, at most 20 MB): such a file is shown as it arrives and can be typed in once whole, with no mode; anything else is one sentence ("chart.png isn't text: a PNG image, 312 KB.") with Copy Path. A clean pane follows the file, the first visible line kept and the changed lines barred for 10 s; typed in, it carries a dot in its title and on its tree row, never takes the workspace's text by itself, and says "Changed on the workspace while you typed." with Compare and Discard Mine; undoing back to what was read makes it clean and following again. Clean means the very bytes read: CRLF, a BOM, mixed endings and no final newline come back byte for byte. Compare opens the conflict sheet: theirs and yours side by side, scrolling together, with Keep Mine, Keep Theirs and Cancel and no default. ⌘S writes the text whole against the version read, one save at a time, and only once the file is all in view (a save while it loads says it is still loading); over a newer file it brings up the sheet, whose Keep Mine and Keep Theirs act on the version it shows, a file changed again being shown again; a file grown past 20 MB while open keeps the typed text and says it can no longer be saved here. Closing the file, opening another into its pane, closing its tab and quitting ask Save, Discard or Cancel; closing the window loses nothing and asks nothing. The keys move between the tree, the terminals and the file by Select Next and Previous Split and Select Split; ⌘W in the file closes the file, never a terminal; a zoomed terminal hides it; hiding the files panel leaves it open. A card over a terminal now changes look by its layers' colours alone, painting nothing over the panes.
