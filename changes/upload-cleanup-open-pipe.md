- **The upload cleanup's tests end the removals and sweeps they start, so none leaves a script's pipe to the class's check of open descriptors.** A removal or sweep closes its script's output after it has seen the script exit, and the JDK's reaper closes it after waking that wait. A test that ended at the exit could reach the check before either, which failed one full build in seven. Each test now closes its cleanup as the host does when it stops, and a test holds both closes to pin the window. Tests only; nothing a person runs changed.
