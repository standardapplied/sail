- **A local host test counts only the descriptors the host left open.** `LocalPtyHostTest`'s stop scenario compared the whole process's descriptor count before and after a host cycle, and failed on CI (596 before, 594 after) when, in a test fork that had run other classes first, a client they left (an HTTP client's selector: an eventfd and an epoll descriptor) was closed as it was collected. It now asserts that no descriptor is open after the cycle that was not open on the same file before it, keyed by number and file key, so a descriptor someone else closes meanwhile is no concern of the host's, while one the host leaves is still named; a channel closed during the cycle stands for the foreign close.
