- **Every sail-infra test class closes what it opens, and a JUnit extension holds it to that.** `ClosesWhatItOpens`, registered for the whole module, lists the fork's descriptors before each class and fails the class after its `@AfterAll` if one it did not start with is still open, naming each by number and target; on Linux only, where `/proc/self/fd` names targets. The JVM's own are not counted: the class path's jars and the kernel's random sources by target, and NIO's pre-close socket and the virtual-thread pollers by loading the two JDK classes that open them before the first listing. The classes that left hundreds of descriptors open now close them: a class that speaks HTTP makes one client and closes it in `@AfterAll`, a test's databases close when it ends, servers built in a test are started so the JDK releases their sockets, and streams, directory listings and a child's pipes are closed by the test that opened them. `LocalPtyHostTest`'s descriptor listing moved to `OpenDescriptors`, which both use.
